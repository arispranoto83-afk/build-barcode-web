Progressive Web App

URL2Code Full-Stack

Ikon futuristik · Offline-first · REST API

Instalasi Layar Utama: Dilengkapi manifest.webmanifest, ikon 192px & 512px, serta sw.js untuk akses cepat tanpa koneksi.
Backend Express + API: Paket ZIP menyertakan server.js dengan endpoint /api/barcodes, database JSON persisten, dan short-link pelacak scan /r/:kode.
Web Share Target: Setelah diinstal di HP dari server HTTPS, Anda bisa langsung membagikan tautan dari browser ke URL2Code.

Jika tombol instal otomatis tidak muncul di browser, gunakan menu Tambahkan ke Layar Utama (Android/iOS) atau jalankan paket full-stack ZIP via npm start.
